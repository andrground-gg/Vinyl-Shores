# Vinyl Shores

A top-down 2D exploration and rhythm game developed for Videogame Design and Programming.

- `VinylShoresSource/`: Unity project (Unity 6000.3.12f1). Open this folder in Unity Hub.
- `Documents/`: game design document.
- `Executables/`, `GameplayVideo/`, `Images/`, `References/`: materials for the final submission, to be added as available.

Visual assets: Ninja Adventure by pixel-boy and AAA, https://pixel-boy.itch.io/ninja-adventure-asset-pack.
